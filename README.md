Enough AI on HN
---------------

I'm tired of reading about AI stuff on Hacker News, so I wrote this browser
extension to automatically hide AI-related submissions.  It injects a button
into the upper-right corner of the main page.  When you click the button, any
submission titles containing AI-related terms will be Hidden.

If you want to go dig them back up after they've been hidden, you can use the
Hidden link in your HN profile to find all the AI stories that were hidden.

I've only tested it on Firefox, but it's pretty simple so it will probably work
in other browsers, too.
